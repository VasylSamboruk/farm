📜 ТЕХНІЧНЕ ЗАВДАННЯ: 2.5D Ізометрична Браузерна Ферма🏗 1. Технологічний СтекДвижок гри (Canvas): PixiJS v8 (ізометричний рендер, відмінна продуктивність для сотень об'єктів).Інтерфейс (HUD / Меню / Адмінка): React + TypeScript + Vite + React Router (всі вікна, склади, повзунки висять поверх Canvas).Бекенд (Сервер): Node.js + Express.js.База Даних: MongoDB + Mongoose (документо-орієнтована база, ідеальна для ігрового стейту та інвентарів).Авторизація: JWT (JSON Web Tokens) + bcrypt для безпечного шифрування паролів.🛡 2. Архітектура "Server-Authoritative" (Анти-Чіт)Клієнт (PixiJS) нічого не вирішує, він є лише "екраном", який малює красиву картинку.Всі таймери (скільки росте соняшник), винагороди (скільки яєць дає курка) та ціни знаходяться у Майстер-Конфігу на сервері (в MongoDB).Логіка роботи: Клієнт каже: "Я клікнув на корову, хочу зібрати молоко". Сервер заглядає в базу, перевіряє: "А чи дійсно пройшло 2 хвилини з минулого збору?". Якщо так — сервер додає молоко в інвентар гравця, зберігає час збору і каже клієнту: "Успіх, малюй анімацію і додай молоко на склад". Це унеможливлює злом через консоль браузера.🗄 3. Структура Бази Даних (MongoDB)У нас буде 3 головні колекції (аналог таблиць).1. Колекція Users (Дані Гравців)username / passwordHash: Дані для входу.role: user або admin.coins: Баланс монет (напр., 1500).xp: Поточний досвід.level: Рівень гравця (впливає на доступність товарів у магазині).inventory: Об'єкт зібраних ресурсів (Наприклад: { "egg": 15, "milk": 5, "sunflower": 100 }).2. Колекція Farms (Поле гравця)Кожен гравець має один великий документ, який описує його поле.userId: Кому належить ферма.tiles: Масив усіх розміщених об'єктів. Кожен об'єкт містить:x, y: координати на ізометричній сітці.itemId: ідентифікатор товару (напр., 'animal_cow').isDirt: чи скопана ця клітинка лопатою.stage: поточна стадія росту (для рослин і дерев).placedAt / lastHarvestedAt: серверні мітки часу (timestamps) для математики таймерів.3. Колекція GameConfig (Майстер-Конфіг гри)Адмін може змінювати ці параметри прямо через React-адмінку на льоту, не зупиняючи сервер!itemId: "animal_chicken"type: "ANIMAL"price: 100 (ціна покупки)sellPrice: 10 (за скільки можна продати одне яйце на ринку)size: { w: 1, h: 1 } (габарити на сітці)growthTimeMs: 0 (тварини не ростуть, а рослини, наприклад, 60000 мс)productionTimeMs: 90000 (раз на 1.5 хвилини дає продукцію)yieldItem: "egg" (що саме падає в інвентар при зборі)yieldAmount: 1 (кількість)yieldXp: 5 (скільки досвіду дає дія)🎮 4. Ігрові Механіки4.1. Об'єкти на полі🌱 Рослини (CROP): Можна посадити тільки на Грядку (isDirt = true). Ростуть заданий сервером час. При зборі врожаю дають ресурс у Склад (напр., "wheat") і зникають, залишаючи порожню грядку.🌳 Дерева (TREE): Садяться на звичайну Траву. Мають стадії росту. Після виростання плодоносять циклічно. Після збору плодів дерево не зникає, таймер запускається заново.🐄 Тварини (ANIMAL): Ставляться на Траву. Одразу дорослі. Можуть займати кілька клітинок (наприклад, корова 2x1). Циклічно дають ресурси (яйця, молоко) на Склад.🚧 Декор (DECOR): Ставиться для краси на Траву. Не має таймерів, приносить одноразовий XP при встановленні.4.2. Інструменти Гравця⛏ Лопата: Скопує звичайну Траву в Грядку. Працює тільки на порожніх клітинках.✋ Переміщення: Дозволяє взяти об'єкт і перетягнути його на інше місце. Сервер перевіряє розміри об'єкта (size) і не дає поставити корову (2x1) туди, де є лише 1 вільна клітинка.🔄 Обертання: Дзеркальне відображення об'єкта (зміна flipX у PixiJS).🗑 Видалення (Смітник): Знищує об'єкт з поля назавжди. Гроші не повертаються. Клітинка знову стає звичайною Травою.4.3. Склад (Інвентар) та РинокЗбір: Коли гравець клікає на готову курку/дерево, ресурс (yieldItem) потрапляє до inventory в колекції Users.Склад (UI): React-вікно, де гравець бачить свої ресурси: "🥚 Яйця: 15 шт", "🥛 Молоко: 5 шт".Продаж: У вікні Складу гравець вибирає товар, виставляє повзунок кількості (наприклад, продати 10 яєць із 15). Натискає "Продати".Бекенд-транзакція: Сервер віднімає 10 яєць з інвентарю, множить на sellPrice (з GameConfig) і додає монети на баланс гравця.👑 5. Адмін-Панель (Керування грою)Окремий закритий маршрут у React (доступний тільки гравцям з role === 'admin').Управління економікою: Таблиця всіх об'єктів гри. Адмін може змінити вартість корови, час її росту, нагороду в XP чи ціну продажу молока. Зміни миттєво зберігаються в БД і починають діяти для всіх гравців.Керування гравцями: Адмін може знайти гравця за username, подивитися його баланс, рівень та інвентар, а також видати монети чи предмети вручну.🗺 6. ПОКРОКОВИЙ ПЛАН РОЗРОБКИ (Roadmap)КРОК 1: Бекенд та Авторизація (Node.js + MongoDB)Ініціалізація сервера. Підключення БД Mongoose.Створення схем: User, Farm, GameConfig.Написання маршрутів (routes) для Реєстрації та Входу з видачею JWT-токена.КРОК 2: Фронтенд Авторизація (React + Vite)Створення красивого екрану Входу / Реєстрації.Налаштування React Router: створення захищених маршрутів (гра недоступна без авторизації, користувача перекидає на форму входу).КРОК 3: Ігровий Рушій та Preloader (PixiJS)Вбудовування PixiJS Application всередину React-компонента (GameCanvas).Створення AssetLoader: завантаження всіх текстур (трава, корови, рослини) з відображенням прогрес-бару 0-100% у React.КРОК 4: Ізометрична Сітка та КамераМатематика ізометрії (перетворення 2D-координат екрану в 3D-ромбики).Генерація базового поля з трави (наприклад, сітка 15x15).Додавання механіки Drag (перетягування карти мишкою) та Zoom (коліщатком).КРОК 5: Синхронізація Конфігу та Рендер об'єктівЗапит на бекенд для отримання GameConfig та стану поля Farm при старті гри.Розміщення збережених об'єктів на полі з урахуванням Depth Sorting (сортування по осі Y, щоб об'єкти спереду правильно перекривали об'єкти ззаду).КРОК 6: Механіка Інструментів та ВалідаціяСтворення UI панелі інструментів (Магазин, Лопата, Смітник, Переміщення).Логіка кліків: локальна перевірка -> запит на сервер -> підтвердження -> малювання об'єкта.КРОК 7: Таймери, Збір та СкладЛогіка відліку часу на клієнті (відображення стрілочок і барів прогресу).Серверна обробка збору: перевірка часу, нарахування ресурсів в inventory.Створення React-вікна "Склад" для перегляду зібраного.КРОК 8: Ринок та АдмінкаМеханіка продажу зі Складу (повзунок кількості -> обмін на монети).Створення React-сторінки "Адмін-панель" для редагування економіки (CRUD операції для колекції GameConfig).
